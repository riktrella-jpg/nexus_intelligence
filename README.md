## ⚡ Inicio Rápido Local (Windows)

Ejecuta el script de inicio en la raíz del proyecto:

```cmd
iniciar.bat
```
o en PowerShell:
```powershell
.\iniciar.ps1
```
Esto levantará automáticamente el **Backend FastAPI** en `http://127.0.0.1:8000` y el **Frontend Next.js** en `http://127.0.0.1:3000`.
